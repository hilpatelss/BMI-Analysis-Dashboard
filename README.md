# 🩺 BMI Analysis Dashboard | Power BI

## 📌 Project Overview

The BMI Analysis Dashboard is an interactive Power BI project designed to analyze Body Mass Index (BMI), health risk levels, body fat percentage, daily calorie intake, and demographic trends. The dashboard enables users to explore health-related metrics through dynamic visualizations and filters, helping identify patterns across different BMI categories, genders, age groups, and activity levels.

---

## 🎯 Objectives

- Analyze BMI distribution across the population.
- Identify health risk levels associated with BMI classes.
- Compare weight and body fat percentage by gender and age.
- Examine daily calorie intake across BMI categories.
- Provide an interactive dashboard for health insights.

---

## 📂 Dataset Features

The dataset contains health-related information including:

- Age
- Gender
- Height (cm)
- Weight (kg)
- BMI
- BMI Class
- Body Fat Percentage
- Daily Calorie Intake
- Activity Level
- Health Risk Level

---

## 📊 Dashboard Features

### KPI Cards

- Highest BMI
- Lowest BMI
- Average Height
- Average Weight
- Average Body Fat Percentage
- Average Daily Calorie Intake

### Interactive Filters

- Gender
- Activity Level
- BMI Class
- Health Risk Level

### Visualizations

- Stacked Column Chart
  - BMI Class by Health Risk Level and Gender

- Pie Chart
  - Distribution of BMI Classes

- Line Chart
  - Average Body Fat Percentage by Age

- Treemap
  - Average Daily Calorie Intake by BMI Class

- Sankey Chart
  - Average Weight by Gender and Activity Level

---

## 📈 Key Insights

- Normal Weight represents the largest BMI category.
- Body fat percentage generally increases with age.
- Higher BMI classes consume more daily calories on average.
- Health risk increases significantly in obesity categories.
- Activity level influences average body weight across genders.
